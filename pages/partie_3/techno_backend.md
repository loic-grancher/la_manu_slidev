## Technologies backend

- Langage : Javascript
- Runtime (Environnement d'exécution): **NodeJS**
- Framework : **ExpressJS**
- Base de données: **PostgreSQL**

L'Api constitue la partie logique et fonctionnelle de l’application, en gérant les requêtes du client, la *logique métier*, l’accès aux *données* et les réponses renvoyées au client..
